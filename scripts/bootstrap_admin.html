🔐 إنشاء أول مدير للنظام

Bootstrap First Admin

⚠️ تحذير أمني
هذه الصفحة لإنشاء أول مدير فقط. بعد إنشاء أول مدير، استخدم لوحة التحكم لإضافة مدراء آخرين.

📝 خطوات الإعداد:

  1. قم بتشغيل الأمر التالي في Terminal:
  2. firebase functions:config:set admin.bootstrap_secret="YOUR_SECRET_KEY_HERE"
  3. استبدل YOUR_SECRET_KEY_HERE بمفتاح سري قوي
  4. أعد نشر الـ Cloud Functions: firebase deploy --only functions
  5. املأ النموذج أدناه واستخدم نفس المفتاح السري
