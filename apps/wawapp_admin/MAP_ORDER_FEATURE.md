# ميزة إنشاء الطلبات مع الخريطة التفاعلية 🗺️

## نظرة عامة

تم إضافة ميزة جديدة للوحة الإدارة تتيح للمسؤول إنشاء طلبات جديدة باستخدام خريطة تفاعلية لاختيار مواقع الاستلام والتسليم، مع حساب السعر تلقائياً بناءً على المسافة.

## المميزات ✨

### 1. اختيار الموقع على الخريطة
- **خريطة تفاعلية** باستخدام OpenStreetMap (flutter_map)
- **اختيار دقيق** للموقع بالنقر على الخريطة
- **عرض العنوان** تلقائياً باستخدام Reverse Geocoding (Nominatim API)
- **عرض الإحداثيات** (خط الطول والعرض)
- **علامة قابلة للسحب** على الخريطة

### 2. حساب السعر التلقائي 💰
- **حساب المسافة** باستخدام معادلة Haversine
- **حساب السعر** بناءً على:
  - السعر الأساسي: 60 MRU
  - السعر لكل كيلومتر: 20 MRU
  - الحد الأدنى للسعر: 100 MRU
  - التقريب إلى أقرب 5 MRU

### 3. واجهة مستخدم حديثة 🎨
- **تصميم نظيف** وسهل الاستخدام
- **بطاقات تفاعلية** لعرض المواقع
- **ملخص السعر** مع تفاصيل الحساب
- **رسائل توضيحية** للمستخدم
- **دعم كامل للغة العربية**

## كيفية الاستخدام 📖

### 1. فتح شاشة إنشاء الطلب
من شاشة الطلبات، اضغط على زر **"إضافة طلب"**

### 2. إدخال معلومات العميل
- أدخل رقم هاتف العميل (بدون كود الدولة +222)

### 3. اختيار موقع الاستلام
1. اضغط على بطاقة **"موقع الاستلام"**
2. ستفتح خريطة تفاعلية
3. اضغط على الموقع المطلوب على الخريطة
4. سيظهر العنوان تلقائياً
5. اضغط **"تأكيد الموقع"**

### 4. اختيار موقع التسليم
- كرر نفس الخطوات لموقع التسليم

### 5. مراجعة السعر
- سيتم حساب المسافة والسعر تلقائياً
- ستظهر بطاقة ملخص السعر مع التفاصيل

### 6. إنشاء الطلب
- اضغط على زر **"إنشاء الطلب"**
- سيتم إنشاء الطلب وإضافته إلى النظام

## معادلة حساب السعر 🧮

```
المسافة = حساب المسافة بين نقطتين (Haversine)
السعر الأساسي = 60 MRU
السعر الإضافي = المسافة × 20 MRU/كم
السعر الإجمالي = السعر الأساسي + السعر الإضافي
السعر النهائي = max(السعر الإجمالي، 100) مقرب لأقرب 5
```

**مثال:**
- المسافة: 3.5 كم
- السعر الأساسي: 60 MRU
- السعر الإضافي: 3.5 × 20 = 70 MRU
- السعر الإجمالي: 60 + 70 = 130 MRU
- السعر النهائي: 130 MRU (مقرب)

## API المستخدمة 🌐

### Nominatim (OpenStreetMap)
- **الاستخدام:** Reverse Geocoding (تحويل الإحداثيات إلى عنوان)
- **الرابط:** `https://nominatim.openstreetmap.org/reverse`
- **مجاني:** نعم
- **حد الاستخدام:** 1 طلب/ثانية

**ملاحظة:** يتم إرسال `User-Agent: WawApp-Admin/1.0` مع كل طلب كما هو مطلوب من سياسة الاستخدام.

## التحسينات المستقبلية 🚀

1. **البحث عن العناوين**
   - إضافة شريط بحث للعناوين
   - اقتراحات تلقائية أثناء الكتابة

2. **حفظ المواقع المفضلة**
   - حفظ المواقع الشائعة
   - الوصول السريع للمواقع المحفوظة

3. **عرض الطريق**
   - رسم الطريق بين نقطتي الاستلام والتسليم
   - عرض الوقت المتوقع للرحلة

4. **تحسين الأداء**
   - Cache للعناوين المستخدمة
   - تحميل الخريطة بشكل أسرع
