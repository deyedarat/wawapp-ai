# Custom Notification Sounds

## Required File
- `new_order.mp3` — Custom sound for new order notifications

## Specifications
- Format: MP3
- Duration: 2-5 seconds
- Sample rate: 44100 Hz
- Bit rate: 128-192 kbps
- Volume: Normalized (-14 LUFS recommended)

## Free Sources
- https://freesound.org/search/?q=notification
- https://notificationsounds.com/
- https://mixkit.co/free-sound-effects/notification/

## Important
- File MUST be named exactly `new_order.mp3` (lowercase, no spaces)
- Android references it as `R.raw.new_order` (without extension)
- After adding the file, rebuild the app for changes to take effect
